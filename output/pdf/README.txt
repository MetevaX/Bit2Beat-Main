Electronic Circuits I - 30-mark practice midterm

Start with electronic_circuits_midterm.pdf (90 minutes).
The separate solutions PDF includes a proposed marking scheme.
Read exam_style_analysis.pdf for evidence and coverage limitations.

Each PDF has matching self-contained LaTeX source. All circuit diagrams are
vector drawings using circuitikz; no external image assets are required.
Compile each .tex file with pdflatex using TeX Live or MiKTeX.
Required packages: circuitikz, lmodern, amsmath, geometry, enumitem, fancyhdr,
booktabs, xcolor and hyperref.

Original practice material, not an official exam or forecast.
Source folder links are included in the analysis PDF.
