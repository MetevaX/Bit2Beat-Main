# Bit2Beat Documentation

This folder contains documentation, notes, design architecture specs, and research references for the **Bit2Beat** NASA Space Apps Challenge project.

## Important Note on Large Media Files

To keep the Git repository lightweight and clone speeds fast:
- **Do NOT commit large media files** into this repository (e.g. `.mp4`, `.mov`, `.avi`, `.psd`, high-res audio exports).
- Large media files—including the **Manim animation video**, high-resolution screen recordings, and the final slide deck presentation—are hosted centrally on the **Team Google Drive**.
